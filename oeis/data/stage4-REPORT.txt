## A325549

> Number of necklace compositions of n with distinct circular differences.

[A325549](https://oeis.org/A325549).

Previous range 1..25. New range 26..40. [Complete b-file](results/b325549.txt).

Method 1: C++ recursively enumerates compositions beginning with a least part, rejects repeated adjacent differences, tests lexicographic minimality over rotations, and checks the closing difference.

Method 2: Python enumerates all rooted compositions with distinct circular differences, counts them separately by length k, and sums count(k)/k. A nontrivial period would repeat a circular difference, so the rotation action is free for length > 1. Singleton compositions also have orbit size one.

Verification wall seconds: method 1 3.136913; method 2 218.631371. Timings are measured wall time, not CPU estimates.

## A336131

> Number of ways to split an integer partition of n into contiguous subsequences all having different sums.

[A336131](https://oeis.org/A336131).

Previous range 0..17. New range 18..30. [Complete b-file](results/b336131.txt).

Method 1: Python enumerates integer partitions and recursively chooses the endpoint of each segment, retaining a set of earlier segment sums. Reversing a partition reverses each split bijectively, so the ascending generator counts the OEIS descending convention.

Method 2: C++ independently enumerates descending partitions. It processes gaps as cut or join decisions, carrying a streaming current sum and a bitmask of completed sums. Every gap choice is visited, and only distinct completed sums survive.

Verification wall seconds: method 1 3.762382; method 2 0.949358. Timings are measured wall time, not CPU estimates.

## A353426

> Number of integer partitions of n

[A353426](https://oeis.org/A353426).

The entry counts the empty partition, singletons, and partitions whose multiplicity multiset is contained in the partition and recursively satisfies the same condition.

Previous range 0..40. New range 41..60. [Complete b-file](results/b353426.txt).

Method 1: Python enumerates ascending integer partitions. Counter objects give multiplicities and test multiset containment; the predicate recurses on the sorted multiplicities until a singleton or the empty partition.

Method 2: C++ independently enumerates descending partitions and iteratively transforms ordered frequency maps. At each step it compares required multiplicities against available counts. No Python generator or predicate is reused.

Verification wall seconds: method 1 25.106351; method 2 3.639136. Timings are measured wall time, not CPU estimates.

## A320052

> Number of product-sum knapsack partitions of n.

[A320052](https://oeis.org/A320052).

Previous range 0..12. New range 13..35. [Complete b-file](results/b320052.txt).

Method 1: Python obtains all multiset partitions by inserting the last element into a block or starting a new block, sorting and deduplicating the resulting block tuples. It considers each distinct submultiset and rejects any repeated product of block sums. A part equal to one is rejected immediately because it duplicates the empty product.

Method 2: C++ enumerates possible block multiplicity vectors directly. A nondecreasing list of block-vector indices gives each multiset of blocks once; unused multiplicities are the omitted submultiset. It inserts every product, including the empty product, into a set and rejects the first collision. No labeled-insertion generator or Python code is shared.

Verification wall seconds: method 1 0.335697; method 2 0.373284. Timings are measured wall time, not CPU estimates.

## A304382

> Number of z-trees summing to n. Number of connected strict integer partitions of n with pairwise indivisible parts and clutter density -1.

[A304382](https://oeis.org/A304382).

Previous range 1..50. New range 51..85. [Complete b-file](results/b304382.txt).

Method 1: Python enumerates strict integer partitions, rejects divisibility between parts, checks gcd-graph connectivity, and evaluates sum(omega(part)-1)-omega(lcm(parts)) = -1. Singletons follow the published program and count even for n=1.

Method 2: C++ independently enumerates strict descending partitions. It rejects divisibility, forms the incidence graph between parts and their distinct prime factors, and uses union-find to require a connected acyclic graph. If it has r part vertices and q prime vertices, the density condition is exactly E-r-q=-1, the tree condition.

Verification wall seconds: method 1 4.539077; method 2 0.190799. Timings are measured wall time, not CPU estimates.
