### Exact local halting guards

From a C configuration, a halt before the next C return can only arise from
`C>1001` or `0 C>01`. This follows by inspecting the D0/A path and the F/A
path. After F erases its first 1, A either sees a 0 immediately, in which case
B sees the erased 0, or clears at least one 1, in which case B sees a cleared
0. Neither route reaches B1. A D0 reached from C1 moves A onto the third cell;
the dangerous case is exactly `1001`. A D0 reached from C0 has a 0 on its left;
the dangerous right neighbor is exactly `0 C>01`.

The F scan may instead continue forever into the blank left tail. The finite
return-rule table does not assert that this divergent branch returns. No
argument here transfers these local guards to all blank-start configurations.

### A checked left-word sweep

The certificate also checks a left buffer transducer. Its input letters are
`011`, `0111` and `01111`, and its buffer is four, five or six zeros with A on the first
buffer cell. Each case is an instantiation of the universally proved
`A-left-digit` rule.

| --- | --- | --- | --- | ---: |
| 4 | `011` | 4 | `111` | 11 |

| 6 | `01111` | 6 | `11100` | 13 |

Empty input is identity. Processing the last block leaves a valid buffer for
the remaining prefix, so structural induction proves the sweep over every
finite ternary input word. Give `011`, `0111`, `01111` the values 0, 1, 2.
For k input letters with value sum D, the step count is `11k+D` and the head
displacement is `-(3k+D)`.

A run of four ones creates a six-zero buffer. The next input digit then
emits `11100`. The left-word induction covers all nine buffer/letter cases, including
that emission and an input run of four ones. The binary right parser alone has no case for it.
The E2 row proves one normalization branch: in right-parser state
R1, an `E(2)=11100` block preceded by an output zero and followed by the next
block's first 1 is processed in 19 steps. It changes that preceding output
zero to 1 and reaches R1 in the next block. With a preceding output 1, the
machine instead invokes the left borrow and re-enters a larger left sweep.
The two-parameter borrow row proves two adjacent borrow operations without
assuming the exterior context. Both scans have checked induction proofs. Its
new C position may still read zeros and invoke another borrow; the induction
connecting that recursive case to the entire processed prefix remains
unproved. The two-letter right parser therefore remains incomplete for the
full counter.

## Concrete discovery and arithmetic model

[stage2b_discover.py](../tools/stage2b_discover.py) saves C frontier returns
from blank tape. A frontier is C strictly right of every 1. The first
million-step trace contains 5350 frontier records. Encoding each run of ones
between the rightmost double-zero delimiter and the final lone 1 by its length
minus two gives a base-minus-two number

`V(d1,...,dk) = sum(d_i * (-2)^(k-i))`.

For the 2645 checked pairs of even-index frontier records after step 10000,
the difference is exactly minus two. This is an observation, not induction.
The [analysis JSON](../data/stage2b/024-counter-analysis.json) and
[the original trace](../data/stage2b/024-frontiers-million.jsonl) preserve it.

A separate instrumented direct simulation ran through one billion steps and
agreed with the existing simulator's final state, head, span and ones. Its
[phase-event log](../logs/stage2b/024-frontier-billion-events.jsonl) records
counter-width changes and failures of the simple encoding. The counter is
rebuilt; one cannot extend the usual minus-two rule through every event.
At the saved frontier after the billion-step checkpoint, the 46-digit word has
`V=-37714097161024` and unsigned residue `32654647016640` modulo `2^46`.
The exact [frontier record](../data/stage2b/024-frontier-billion.json) includes
its entire word and the left run length. An unsigned residue gives a useful
finite counting-phase observation, but it is not a verified global recurrence.

minus two and must be followed by runs `3,2`. In the saved even-frontier trace

[The context count](../data/stage2b/024-redundant4-contexts.json) is finite evidence.

not require the leading or trailing run to retain its initial value. It is
