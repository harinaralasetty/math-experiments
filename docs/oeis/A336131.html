New terms for OEIS A336131: partition splits into consecutive groups with different sums

By Hari Naralasetty (GitHub · LinkedIn) · 2026-10-22

This page gives 13 independently checked new terms for OEIS A336131: partition splits into consecutive groups with different sums.

Definition

Number of ways to split an integer partition of n into contiguous subsequences all having different sums.

Quoted from OEIS A336131, as cached in the source workspace.

Published range and extension

The cached published range was 0 through 17. The extension adds indices 18 through 30, giving 13 new terms. These terms have not yet been submitted to the OEIS.

Download the complete A336131 b-file, published and new rows.

Two computation methods

Python enumerates ascending integer partitions and recursively chooses segment endpoints while tracking earlier segment sums.

C++ enumerates descending partitions and chooses cut or join at each gap, tracking completed sums in a bitmask.

Reversing a partition gives a one-to-one correspondence between its splits and those of the reversed partition.

Reproduce

From the repository root, run make -C oeis verify. It recomputes all extensions with both methods and compares every row, including the published overlap. C++ and Python are required.
