A353390 verified term extension

By Hari Naralasetty (GitHub · LinkedIn) · Published 21 October 2026

Definition

Number of compositions of n whose own run-lengths are a subsequence (not necessarily consecutive).

Quoted from OEIS A353390, as cached in the source workspace.

Published range and extension

The cached published range was 0 through 17. The extension adds indices 18 through 32, giving 15 new terms. These terms have not yet been submitted to the OEIS.

Download the complete A353390 b-file, published and new rows.

Two computation methods

Recursive composition enumeration, run-length extraction and forward greedy subsequence matching.

Independent binary cut-mask enumeration and run-length subsequence testing.

The extension uses separate C++ programs. Neither reads expected terms to construct its answer.

Reproduce

From the repository root, run make -C oeis verify. It recomputes all extensions with both methods and compares every row, including the published overlap. C++ and Python are required.
