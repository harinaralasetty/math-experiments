New terms for OEIS A383710: partitions admitting no disjoint strict refinements

By Hari Naralasetty (GitHub · LinkedIn) · 2026-10-22

This page gives 45 independently checked new terms for OEIS A383710: partitions admitting no disjoint strict refinements.

Definition

Number of integer partitions of n such that it is not possible to choose a family of pairwise disjoint strict integer partitions, one of each part.

Quoted from OEIS A383710, as cached in the source workspace.

Published range and extension

The cached published range was 0 through 20. The extension adds indices 21 through 65, giving 45 new terms. These terms have not yet been submitted to the OEIS.

Download the complete A383710 b-file, published and new rows.

Two computation methods

Enumerate outer integer partitions and test for pairwise disjoint strict refinements using bitmasks.

Enumerate globally distinct summands, group them into unlabeled blocks, and subtract the distinct feasible block-sum partitions from the total partition count.

Both methods count failures of the refinement condition.

Reproduce

From the repository root, run make -C oeis verify. It recomputes all extensions with both methods and compares every row, including the published overlap. C++ and Python are required.
