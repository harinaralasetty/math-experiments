A383533 verified term extension

Definition

Number of integer partitions of n with no ones such that it is possible to choose a family of pairwise disjoint strict integer partitions, one of each part.

Quoted from OEIS A383533, as cached in the source workspace.

Published range and extension

The cached published range was 0 through 30. The extension adds indices 31 through 75, giving 45 new terms. These terms have not yet been submitted to the OEIS.

Download the complete A383533 b-file, published and new rows.

Two computation methods

Partition generation without ones and backtracking over disjoint strict-partition masks.

Enumerate disjoint strict refinements and aggregate feasible part multiplicities.

The two searches approach the same feasibility condition in opposite directions.

Reproduce

From the repository root, run make -C oeis verify. It recomputes all extensions with both methods and compares every row, including the published overlap. C++ and Python are required.
