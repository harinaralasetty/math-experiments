New terms for OEIS A353426: partitions that recursively contain their multiplicities

By Hari Naralasetty (GitHub · LinkedIn) · 2026-10-22

This page gives 20 independently checked new terms for OEIS A353426: partitions that recursively contain their multiplicities.

Definition

Number of integer partitions of n that are empty or a singleton or whose multiplicities are a sub-multiset that is already counted.

Quoted from OEIS A353426, as cached in the source workspace.

Published range and extension

The cached published range was 0 through 40. The extension adds indices 41 through 60, giving 20 new terms. These terms have not yet been submitted to the OEIS.

Download the complete A353426 b-file, published and new rows.

Two computation methods

Python enumerates ascending partitions and recursively tests whether their multiplicities form a contained multiset satisfying the same condition.

C++ enumerates descending partitions and repeatedly transforms frequency maps, checking the required multiplicities against available counts.

The empty partition and singletons satisfy the condition directly.

Reproduce

From the repository root, run make -C oeis verify. It recomputes all extensions with both methods and compares every row, including the published overlap. C++ and Python are required.
