New terms for OEIS A335457: patterns found in consecutive parts of compositions

By Hari Naralasetty (GitHub · LinkedIn) · 2026-10-22

This page gives 6 independently checked new terms for OEIS A335457: patterns found in consecutive parts of compositions.

Definition

Number of normal patterns contiguously matched by compositions of n.

Quoted from OEIS A335457, as cached in the source workspace.

Published range and extension

The cached published range was 0 through 20. The extension adds indices 21 through 26, giving 6 new terms. These terms have not yet been submitted to the OEIS.

Download the complete A335457 b-file, published and new rows.

Two computation methods

C++ composition enumeration with contiguous-subword normalization and pattern deduplication.

Python binary cut-mask compositions with separately cached rank normalization.

The empty composition and empty pattern follow the cached sequence conventions.

Reproduce

From the repository root, run make -C oeis verify. It recomputes all extensions with both methods and compares every row, including the published overlap. C++ and Python are required.
