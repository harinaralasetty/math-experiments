# HorizonMath batch A report

## Verdict

Best accepted DTS scope: **112**. Best accepted code size: **36**.
Both canonical solutions are the extracted published witnesses unless the promotion log below identifies an improvement. No invalid tabu checkpoint is a solution.
No new record was found. This search does not prove either baseline optimal.

The searches were shorter than the requested wall-time budget. This is a limitation of the campaign reported here.

## Strict verifiers

The DTS checker requires actual integers, normalized increasing rows and globally distinct exact positive differences. The code checker independently computes pairwise Hamming distances from sets of points. Neither reads a claimed score. The benchmark validators are imported without changes and with bytecode writes disabled.
`make verify` passed 14 comparison cases. Published witnesses and canonical solutions were accepted; all deliberately broken cases below were rejected by both checkers. A forged claimed score was ignored.

```sh

make build
.venv/bin/python run_batch.py plans/dts-followup.json

python3 promote_solutions.py

```

The batch runner skips completed jobs with successful exit codes. To run a new seed, copy a plan with new names, seeds and checkpoint paths. Heuristic checkpoints restart from the saved best configuration. CP-SAT internal trees are not serialized. No commit, publication or message to another person was made.
