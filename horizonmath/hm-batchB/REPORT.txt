## Search implementations and executed runs

The descriptions below cover implemented methods. The completed-run table and command/phase logs identify which methods actually ran; prepared methods are not claimed as completed searches.

Covering search targets 29 distinct blocks. The unrestricted CP-SAT model has exact four-subset coverage constraints and necessary degree bounds obtained from links: each point occurs at least 15 times, each pair at least 7 times, each triple at least 3 times. For 29 blocks, a minimum-degree point has degree 15. It can be renamed point 0, with one incident block fixed to {0,...,6}; remaining degrees are sorted separately within the fixed block and its complement. These symmetry restrictions preserve existence. The refined unrestricted run normalizes the best saved near-cover to these labels and uses CP-SAT hint repair. The original implementation is retained as `sources/search_cover_cp_v1.py`.

The weighted tabu search exchanges one selected block for one block covering an uncovered four-subset. It updates coverage counts and increases penalties for persistent uncovered subsets, with periodic penalty decay and perturbations. Later runs correct the aspiration rule to compare exact uncovered counts; weighted penalties rank moves only. The initial implementation is preserved as `sources/search_cover_tabu_v1.cpp`. Checkpoint files containing nonzero uncovered counts are invalid candidates and are never submitted as solutions.

The refined CP-SAT model starts from an explicitly verified element-minimal (12,6,3) link family, selects completions of its three short blocks, and chooses fourteen extension blocks. It is a restricted construction search; a failed run is not a proof that no 29-block covering exists.

Schur search uses the full exact Boolean encoding: exactly one color per integer and a clause forbidding each monochromatic x+y=z, with doubled variables deduplicated in the SAT implementation. Color names are normalized by first occurrence where required. CP-SAT searches both unrestricted and reflected colorings in separate runs; reflection is an explicit restriction, not a theorem about all optima.

The SAT neighborhood method freezes part of a candidate, releases endpoints of violated sums, and solves the complete formula under those assumptions using bounded CaDiCaL conflict budgets. It mixes local repairs with much larger released neighborhoods; later runs also release entire color classes for component trades. An UNSAT neighborhood rules out only those frozen assignments. UNKNOWN is recorded separately.

The Schur tabu engine maintains weighted conflict costs for recoloring each integer, follows a currently violated sum, and updates only incident constraints. Persistent conflicts receive increasing weights, with decay and perturbed restarts. It searches targets 537 and 538. Later runs alternate standard weights with higher initial weights on doubling constraints, and refresh equal-score checkpoints to diversify exact repair neighborhoods. Another variant first repairs the doubling-edge forest, then forbids every move that would create a doubling violation. All genuine sum-free colorings satisfy that invariant. Modular permutations of the published 536 construction provide diverse seeds, and the high-depth seed was independently verified after relabeling. Later runs load the best matching saved checkpoint before changing seeds.

The additional covering probe fixes the other published minimum-link family (Figure 6 of Gordon et al., https://www.dmgordon.org/papers/c-12-6-3.pdf) and searches for fourteen extension blocks. Its triple coverage was enumerated before use.

Group-invariant CP-SAT models select entire orbits of seven-subsets under permutations with cycles of length three, five, or two. Coverage is checked on target-subset orbit representatives, with exact multiplicities in degree constraints. Incidence and congruence arguments strengthen the fixed-point degree constraints. These searches cover the stated symmetry classes only; a negative result does not rule out asymmetric coverings.

A finite repair check swaps two colors on induced hypergraph components after excluding the sole bad edge; every proposed repair is checked exactly. The algebraic part multiplies integer labels modulo N+1 by every invertible multiplier for saved one-violation candidates, then applies the exact Schur verifier. This transformation is treated as candidate generation; sum-freeness is never assumed to be preserved. The check runs at an idle phase boundary.

A final exact repair builds palette-restricted SAT models for the late one-error candidate: selected color classes may be recolored within their palette, while all other classes stay fixed. Mixed edges cannot become monochromatic because the palettes are disjoint. Each query has an explicit conflict budget; its status is recorded separately.

## Search limitations and next steps

The CP-SAT runs use floating-point LP guidance internally, but no acceptance decision depends on it: submitted constructions pass independent integer verifiers. A time-limited UNKNOWN result is not an infeasibility certificate. Link-family, permutation-group, and reflection constraints restrict particular runs; they are not global nonexistence proofs. SAT neighborhood UNSAT results apply only to the frozen assignments for that query. The high-depth Schur seed is a modular relabeling of the published construction, verified before use. Checkpoints preserve the best construction state; restarting a solver does not resume its internal learned clauses or full RNG state.
