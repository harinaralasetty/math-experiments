## Ranked shortlist for a new record (strong code model, ~2 days, Apple M4 10 cores, 17 GB)

1. **dts_7_5_min_scope** (112 -> 111): small finite search space; current record came from dedicated FPGA search, but a well-pruned SAT/CP or bitset backtracking over 7x6 arrays with symmetry breaking is laptop-feasible and verifiable exactly.
2. **cwcode_29_8_5** (36 -> 37, upper 39): gap of 3 to the Johnson bound, record from one 2018 paper; packing search (simulated annealing / exact cover with symmetry groups) on 29 points is cheap.
3. **covering_C13_k7_t4** (30 -> 29, lower 28): tiny instance (715 4-sets, 1716 blocks); ILP/SAT or local search can test 29 directly, though LJCR coverings this small have been heavily searched (and the 2026 LJCR value is unverified).
4. **schur_6** (536 -> 537): upper bound 1836 leaves room, untouched since 2000, and template/SAT methods recently improved S(7), S(8); but the 536 symmetric partitions are well-studied, and the validator rejects the prompt's dict format, so submit a bare list.

Not recommended: kakeya (baseline is a lower bound), turan_petersen (likely extremal), diff_basis (173 contradicts a well-tested conjecture), heilbronn/tammes (decades of optimisation; only float-tolerance "wins"), bklc_68_15 and A21_10 (heavily searched tables).
